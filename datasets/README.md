# Datasets

This folder contains the raw data files used for the iPhone Sales Comparison project.

- `fact_sales_Iphone14.csv` → Sales data for iPhone 14  
- `fact_sales_Iphone15.csv` → Sales data for iPhone 15  
- `dim_stores.csv` → Store dimension data  

These files are the foundation for the analysis and are imported into Power BI for modeling and reporting.
